# 📊 Marketing Campaign & Customer Insights Analytics

An end-to-end marketing analytics project designed to identify valuable customer segments, evaluate campaign performance, analyze preferred channels, and create actionable customer targeting strategies.

The project combines **Python, SQL, and Power BI** to transform raw customer marketing data into business-focused insights.

---

## 🎯 Project Objective

The objective of this project is to analyze customer behavior and campaign performance and answer key marketing questions such as:

- Which customer segments generate the most revenue?
- Which marketing channels have the highest response rates?
- Which customers are most valuable?
- Which customers are at risk of becoming inactive?
- How does campaign engagement affect response rates?
- Which customer groups should be targeted for retention, nurturing, or win-back campaigns?
